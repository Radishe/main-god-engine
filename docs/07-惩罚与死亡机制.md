## 1. 入场押金

> 押金 = min(当前兑换点 × 0.1, 押金上限)

押金上限按**副本阶位**设定（占位，开发测试中拟合）：

| 副本阶位 | 押金上限（占位） |
| :--- | :--- |
| 新手 / 一阶 | 100 |
| 二阶 ~ 三阶 | 300 |
| 四阶 ~ 五阶 | 800 |
| 六阶 ~ 七阶 | 2000 |
| 八阶 ~ 十阶 | 5000 |

## 2. 失败三档

| 失败档位 | 完成度系数 | 惩罚 |
| :--- | :--- | :--- |
| D（轻微失败） | 0.3 | 扣押金 50%，不扣额外兑换点 |
| E（中等失败） | 0 | 扣押金全额 + 扣当前兑换点 10% |
| F（严重失败） | 负数 | 扣押金全额 + 扣当前兑换点 20%~30%，可能触发永久死亡 |

---

## 3. 严重失败递增机制

严重失败与副本内隐藏评分挂钩，**递增式**：

- 每次严重失败，计一次严重失败计数。
- **计数按阶位重置**：每晋升一阶，计数清零。
- **高阶容错更低**：一阶允许 3 次，二阶允许 2 次，三阶以上允许 1 次。
- 达到阈值 → **抹杀**。

**设计意图**：把「永久死亡」从「随机概率」变成「累积后果」。玩家每次严重失败都在逼近死亡线，而不是每次进副本都掷骰子。这更可控，也更有叙事张力。

> 该项对应 [09-待确认细节.md](09-待确认细节.md) 细节 2（倾向选项 B）。

### 3.1 触发严重失败计数的条件清单

- 结算评价为 F。
- 副本内主动放弃。
- 触发致命违规（如利用副本机制漏洞刷取收益，经主神判定）。
- 晋升试炼失败。

---

## 4. 抹杀规则

**抹杀 = 进度清空 + 保留纪念标记**，不是删档。

- 角色回到初始状态（一阶、属性归零、物品清空、技能清空）。
- 玩家保留一个「曾到达 X 阶」的纪念标记（类似死亡记录）。
- 抹杀有痛感，但不至于让玩家彻底弃游。

**单存档约束**：游戏只有一个存档，玩家就是一个「真实的人」。抹杀不可回滚。这强化了无限流的严肃性。

---

## 5. 永久死亡保护

| 玩家阶位 | 永久死亡保护 |
| :--- | :--- |
| 一阶 ~ 二阶 | 永不触发永久死亡。即使进入高阶副本，死亡降级为「严重失败 + 高额扣点」 |
| 三阶以上 | 可能触发永久死亡，且需副本声明 `lethal: true` |

**`lethal` 声明权**：建议高阶副本默认允许 `lethal`，作者可以选择关闭（但关闭后收益打折），防止作者为了收益滥用永久死亡。

---

## 6. 逾期未进入副本

- 判定为**中等失败**（E 档）。
- 押金基数取「下一个应进副本」的押金上限。
- 扣押金全额，扣当前兑换点 10%。
- 完成度系数 0，不产出任何收益。
- 计入阶位进度负向标记。
- 连续逾期两次触发惩罚副本（难度等于当前阶位，收益打八折）。
- 仅可用休息期延长令豁免。

---

## 7. 失败惩罚的执行者

**惩罚的执行者永远是主神引擎，不是副本脚本。**

副本只能申报「失败」这个事件，后果由主神裁定。副本不能自己写「失败者直接删号」，它只能触发「失败」这个事件。

---

## 8. 最终兑换点公式

> 最终兑换点 = 基础产出值 × 阶位系数 × 完成度系数 × 效率系数 × 惩罚系数

- 基础产出值：来自主神侧任务/物品/能力值表。
- 阶位系数：新手 0.5 到十阶 512.0（占位，待拟合）。
- 完成度系数：S=2.0 到 F=负数。
- 效率系数：1.0 + min(上限, 内部资源余额 / 目标基准总值 × 系数)。加成上限由玩家阶位决定。
- 惩罚系数：失败侧按精神和失败表修正，下限 0.5。
