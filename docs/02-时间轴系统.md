## 0. 审计发现（2026 全量审计）

### 0.1 ⚠️ 逾期惩罚的两根支柱**都是悬空的**

**严重度：中** ｜ **后果：该节逻辑上不可执行**

| 出处 | 依赖 | 问题 |
| :--- | :--- | :--- |
| §1「押金基数取『**下一个应进副本**』的押金上限」 | 「应进副本」的概念 | ❌ **副本分配规则全库不存在** → **基数无法计算** |
| §1「仅可用**休息期延长令**豁免」 | 「休息期」的时长 | ❌ **休息期时长规则不存在** → **道具无法作用于未定义的时间段** |

> **这不是"缺口"，是"逻辑上不可执行的规则"** ——
> 一个道具不能豁免一个不存在的期限，一个基数不能取自一个不存在的序列。

**连带问题（D1 之后）**：押金公式已被推翻（见 [07](07-惩罚与死亡机制.md) §0.1），
因此「押金基数取……押金上限」这一整句**所引用的对象已失效**。

### 0.2 ★ 时间轴与存档的冲突（**本章最大的未解问题**）

用户自述的盲点：

> 如果不能保存，则玩家玩得太累；如果能保存的话，**主神主程序的时间轴就被卡住了，形同虚设**。
> 玩家只需要随便进入一个副本，然后退出保存，则永远不会触发时间轴的提示机制。

**审计结论：这其实是两个不同的问题**，一直被混为一谈：

| # | 问题 | 本质 | 状态 |
| :--- | :--- | :--- | :--- |
| **A** | 存读档是时间旅行 | **不可逆性**问题 | ✅ **已由 D10 关闭**（单机 + 开源 + 不在意作弊） |
| **B** | 进副本就冻结主神倒计时 | **计时基准**问题 | ❌ **未解，且与作弊无关** |

**关于 A**：读档 = 作弊的一种，D10 已明确接受。**不需要技术解决。**

**关于 B**：**正常游玩就会发生** —— 玩家进副本 → 时间轴冻结 → 无论玩多久时间轴都不动。

**可能的解法（待用户确认）**：

> **核心思路：副本不是「暂停」时间轴，而是「消耗」时间轴。**

| 模型 | 副本内如何 | 结果 |
| :--- | :--- | :--- |
| A. 现实时间 | 现实时间照走 | **被"永不上线"卡死** |
| B. 游戏内时间（仅主神空间流逝） | 进副本 = 暂停 | **仍被存档卡死** |
| **C. 混合** | 副本**消耗**时间，不暂停 | ✅ **问题消失** |

**Lead 观察**：本项目的架构**强烈指向 C**，因为：

- [01](01-核心设计哲学.md) §3 已确立「副本世界是**另一个时空**」（无限流标配）
- 本章 §1 有「逾期未进入副本」的惩罚 → 说明主神空间确实有倒计时

**在 C 模型下，本节问题自动消失** —— 时间轴的计时点是**「进入副本」和「离开副本」两个瞬间**，与玩家中途存不存档无关。

**待确认**：

> **时间轴是"玩家多久没进副本就惩罚"（现实时间），还是"玩家在主神空间待了多久"（游戏内时间）？**
>
> Lead 判断：**用户要的是后者。**

## 1. 逾期未进入副本（唯一有素材的部分）

> 来源：`generate_docs.py` 中 07 章第 6 节。

- 判定为**中等失败**（E 档）。
- 押金基数取「下一个应进副本」的押金上限。
- 扣押金全额，扣当前兑换点 10%。
- 完成度系数 0，不产出任何收益。
- 计入阶位进度负向标记。
- 连续逾期两次触发惩罚副本（难度等于当前阶位，收益打八折）。
- 仅可用**休息期延长令**豁免。

### 关联信息

- 逾期惩罚的执行者为**主神引擎**，副本脚本不能自行裁定（见 [07-惩罚与死亡机制.md](07-惩罚与死亡机制.md)）。
- 「休息期延长令」在本套文档中**仅此一处出现**，其获取方式、生效范围、是否可叠加，素材中均无说明。
- 主神空间被设计为**可停留、可交易、可交流的持久化平台**（turn 16，《王牌进化》蓝本），暗示「休整期」是存在的时间段，但**其时长规则无素材**。

## 2. 状态快照（与时间轴的关联待确认）

> 来源：turn 6

副本加载时会**冻结轮回者进入时的状态快照**（入场公证的三件事之一，见 [06-物品与公证体系.md](06-物品与公证体系.md)）。

副本可以读取这个快照，但**所有修改都发生在自己的局部状态里**；只有主神收到结算清单后，才执行一次性的、经过校验的写入。

> 素材中未把「快照」明确定义为时间轴的一层，但这是目前唯一与「进入时点」相关的机制。**是否将其归入三层时间轴，需另行确认。**

## 3. 素材缺口

以下内容属于本章标题范围，**在完整对话（8 轮）与脚本素材中均不存在**，不做推测性填充：

| 缺什么 | 说明 |
| :--- | :--- |
| **三层时间轴** | 三层分别是什么（如：副本内时间 / 主神空间休整期 / 现实时间？）、如何换算、如何计时，**完整对话零提及** |
| **延期道具** | 除「休息期延长令」这个名称外，无任何道具定义、数量、价格或规则 |
| **单机时间校验** | 如何防止玩家修改系统时间（本地时钟篡改、离线时间跳变）——本章标题点名了这个问题，但**素材中完全没有对应内容** |

> 待补充时，建议同时确认「休息期」的时长单位与「逾期」的判定基准，这两者是本章与 07 章的交界处。
