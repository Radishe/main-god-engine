## 0. 审计发现（2026 全量审计）

### 0.1 ⚠️ 完成度系数 **E = 0** 使「达成率」在低档断裂

**严重度：中**

| 出处 | 内容 |
| :--- | :--- |
| §1 表 | E \| **0** |
| D12（正确链条） | 达成率落入**区间** → 定级 |

**矛盾**：D12 要求每个评价是**一段达成率区间**，但 **E 的系数是 0**：

1. **区间断裂**：若 E 是区间，则 `D=0.3` 与 `E=0` 之间的大量达成率（如 0.1~0.3）**无处归级**
2. **失去分辨力**：系数 0 意味着 **E 档收益恒为 0，与达成率大小完全无关** ——
   完成 25% 的玩家与完成 0.1% 的玩家**收益相同**
3. **F 同理**：F 为"负数（按惩罚表）"，但**负数的大小应由达成率决定**，而表里根本没有 F 的值

**建议**：把 E 的系数改为一个**正的小值**（如 0.1），或明确 E/F 使用**分段/连续**而非全表查系数。
否则 D12 的达成率链条**在低档断裂**。

### 0.2 ⚠️ 主线/支线规则（D8）有三处未定

**严重度：中** ｜ **D8 是本项目最重要的新增机制，但落地细节缺失**

D8 原文：

> 主线成功 → 支线收益按 **100%** 计入；主线失败 → 支线收益按 **50%** 计入

**未定问题一：50% 作用在「分值」还是「收益」上？**

（假设总量 100、主线 80、支线共 20，主线失败但支线全清）

| 解读 | 算法 | 达成率 |
| :--- | :--- | :--- |
| (a) 分值侧乘 0.5 | `0 + 20×0.5 = 10` | 10% |
| (b) 支线份额先减半 | `(0 + 20×0.5)/100` | 10% |
| (c) 最终收益乘 0.5 | `(0+20)×0.5 = 10` | 10% |
| (d) 主线份额作废但仍计入分母 | `0/100` | **0%** |

> 前三者结果相同，第四种不同 —— **需明确是"扣分"还是"扣收益"。**

**未定问题二：主线份额是否必须 ≥ 某比例？**

| 决议 | 内容 |
| :--- | :--- |
| D7 | 「滑动变阻器」：给**简单任务多分**，给难任务就少分 |
| D8 | **主线优先**（第一优先级绝对是主线） |

**两条规则在作者操作层面指令相反** —— 作者若照 D7 给跑腿任务分 50%，D8 的"主线优先"就被稀释。

> **D7 与 D8 需要一个仲裁规则**（如"主线份额下限 ≥ 50%"）。

**未定问题三：主线失败后的评价上限**

从"体现高级评价的稀缺性"的表述看，倾向**设上限**（如主线失败 → 最高只能到 C/D）。
但按 [D12](设计决议记录.md) 的链条，**主线失败先扣分再定级，"上限"可能不需要单独设** —— 需确认取哪种。

> 见技术债 [T5](技术债与盲点.md#t5)、[T11](技术债与盲点.md#t11)。

### 0.3 ⚠️ §6「素材缺口」中的「基准分」需限定范围

本章 §6 写「基准分 / 理论最高分……**无基准分定义**」——**这个表述需要精确化**：

[08](08-治理与审核.md) checklist 中有**两个不同宾语**的相近用词：

| 项 | 宾语 | 状态 |
| :--- | :--- | :--- |
| **第 5 项**「基准**分**」 | **副本/任务**评分体系 | ❌ 未定义 |
| **第 7 项**「基准**值**」 | **物品/能力**定价体系 | ✅ **已定义**（[06](06-物品与公证体系.md) §1.2：品质→基准值区间） |

> **说"基准分未定义"是对的；但不能说"基准分/基准值都未定义"。** 二者属**易混**，非术语漂移。

## 3. 评级权归主神

> 来源：turn 12（《轮回乐园》蓝本）

**主神拥有最终的「定价权」和「评级权」**。主神结算时不关心副本内部的经济系统，只认几个抽象指标。

### 3.1 世界结算评价

主神根据结算数据对轮回者做出**世界结算评价**（小说中如 S-、A 级），并可能据此**强制调整其权限等级**。

### 3.2 强制评级与晋升

> ⚠️ **本节不采纳。** 见 [设计决议记录.md](设计决议记录.md) **D3**：用户明确「主神（框架）**不会去判定角色综合实力**，只会判定其等级和阶段，用来匹配副本」。
> 而本节机制的前提正是「主神检测到实力超标」——**与 D3 直接冲突**。
> 原文（出自《轮回乐园》小说设定）仅作参考保留。

> 当检测到轮回者**实力远超当前阶位上限**时，主神会**强制提升其等级并开启晋升试炼**，而不是任由其在低阶副本里「炸鱼」。

**设计意图（小说原文）**：防止高战力玩家滞留在低阶副本刷取低风险收益。

> **替代方案**：防止「高阶炸鱼」改由 [D2](设计决议记录.md) 承担——**高阶进入低阶副本原则上禁止**，靠限阶段道具才可进入且收益打折。该方案不需要主神判定实力。

### 3.3 抽象指标

主神只认以下几类抽象指标，而非副本内部的具体数值：

| 指标 | 来源 |
| :--- | :--- |
| **世界之源 / 战斗贡献** | 副本结束时，主神根据轮回者在副本内的行为（击杀、探索、任务完成度）统一折算为贡献值 |
| 贡献值 → 通用货币 | 按比例转化为主神空间的通用货币 |

> **小说设定示例**：《轮回乐园》中战斗贡献值 0.1% = 乐园币 50。
> ⚠️ **此为本项目参考的小说数值，不是本项目已采纳的数值。** 本项目的数值占位一律见 [09-待确认细节.md](09-待确认细节.md)。

**这意味着**：副本作者只需在结算清单里填写「本次产出：战斗贡献 X 点、可公证物品 ID 列表」，**换算汇率和稀有度映射完全由主神侧的配置文件决定**。副本的自主性止步于产出申报。

## 5. 场景规则标签（差异化评级）

> 来源：turn 16（《王牌进化》蓝本）

副本可按**玩家间的交互规则**而非视觉风格来分类，不同场景适用完全不同的底层交互规则：

- **和平场景**
- **掠夺场景**
- **契约场景**

> 素材给出的是这三个标签的**共同性质**：底层交互规则不同（原文举例「如能否 PVP、交易是否受保护」）。该举例**是对三个标签整体的说明，素材并未逐标签分配规则内容**。

**可落地方式**：让副本作者在申报时选择「场景规则标签」，**主神据此在结算时套用不同的公证与税率规则**。

> 这比单纯按「视觉风格（3D/2D）」分层更进一步——它按玩家间的交互规则来定义副本性质。
