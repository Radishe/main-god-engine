## 1. 评价七档与完成度系数

> 来源：`generate_docs.py` 09 章「完成度系数」占位表（**完整**）。

| 评价 | 占位值 | 状态 |
| :--- | :--- | :--- |
| S | 2.0 | 待拟合 |
| A | 1.3 | 待拟合 |
| B | 1.0 | 待拟合 |
| C | 0.7 | 待拟合 |
| D | 0.3 | 待拟合 |
| E | 0 | 待拟合 |
| F | 负数（按惩罚表） | 待拟合 |

**该系数在结算公式中的位置**：

> 最终兑换点 = 基础产出值 × 阶位系数 × **完成度系数** × 效率系数 × 惩罚系数

见 [07-惩罚与死亡机制.md](07-惩罚与死亡机制.md)。

### 1.1 与失败三档的对应

| 失败档位 | 完成度系数 | 惩罚 |
| :--- | :--- | :--- |
| D（轻微失败） | 0.3 | 扣押金 50%，不扣额外兑换点 |
| E（中等失败） | 0 | 扣押金全额 + 扣当前兑换点 10% |
| F（严重失败） | 负数 | 扣押金全额 + 扣当前兑换点 20%~30%，可能触发永久死亡 |

## 2. 评价与物品品质

> 来源：`generate_docs.py` 06 章第 3 节。

**品质上限由副本阶位 + 结算评价共同决定。**

- 三阶副本的 **S 评价**才可能产出 **A 品质**物品。
- 七阶副本的 **B 评价**就可能产出 A 品质物品。

## 3. 评级权归主神

> 来源：turn 12（《轮回乐园》蓝本）

**主神拥有最终的「定价权」和「评级权」**。主神结算时不关心副本内部的经济系统，只认几个抽象指标。

### 3.1 世界结算评价

主神根据结算数据对轮回者做出**世界结算评价**（小说中如 S-、A 级），并可能据此**强制调整其权限等级**。

### 3.2 强制评级与晋升

> 当检测到轮回者**实力远超当前阶位上限**时，主神会**强制提升其等级并开启晋升试炼**，而不是任由其在低阶副本里「炸鱼」。

**设计意图**：防止高战力玩家滞留在低阶副本刷取低风险收益。这是「评级权在主神」的具体体现——玩家无法自行选择留在舒适区。

> 该机制与 [09-待确认细节.md](09-待确认细节.md) 细节 3（越阶许可）相关，但**两者不是同一件事**：细节 3 讨论的是玩家**主动**申请越阶，强制晋升讨论的是主神**主动**拉高玩家等级。素材中未说明两者的优先级关系。

### 3.3 抽象指标

主神只认以下几类抽象指标，而非副本内部的具体数值：

| 指标 | 来源 |
| :--- | :--- |
| **世界之源 / 战斗贡献** | 副本结束时，主神根据轮回者在副本内的行为（击杀、探索、任务完成度）统一折算为贡献值 |
| 贡献值 → 通用货币 | 按比例转化为主神空间的通用货币 |

> **小说设定示例**：《轮回乐园》中战斗贡献值 0.1% = 乐园币 50。
> ⚠️ **此为本项目参考的小说数值，不是本项目已采纳的数值。** 本项目的数值占位一律见 [09-待确认细节.md](09-待确认细节.md)。

**这意味着**：副本作者只需在结算清单里填写「本次产出：战斗贡献 X 点、可公证物品 ID 列表」，**换算汇率和稀有度映射完全由主神侧的配置文件决定**。副本的自主性止步于产出申报。

## 5. 场景规则标签（差异化评级）

> 来源：turn 16（《王牌进化》蓝本）

副本可按**玩家间的交互规则**而非视觉风格来分类，不同场景适用完全不同的底层交互规则：

- **和平场景**
- **掠夺场景**
- **契约场景**

> 素材给出的是这三个标签的**共同性质**：底层交互规则不同（原文举例「如能否 PVP、交易是否受保护」）。该举例**是对三个标签整体的说明，素材并未逐标签分配规则内容**。

**可落地方式**：让副本作者在申报时选择「场景规则标签」，**主神据此在结算时套用不同的公证与税率规则**。

> 这比单纯按「视觉风格（3D/2D）」分层更进一步——它按玩家间的交互规则来定义副本性质。

## 6. 素材缺口

| 缺什么 | 现有素材 |
| :--- | :--- |
| **任务评分** | 仅提到「任务分值设计」「无畸高单任务」（[08-治理与审核.md](08-治理与审核.md) checklist 第 6 项），**无评分方法** |

| 各评价档位的判定标准 | 无素材（什么表现算 S、什么算 B） |
| 场景规则标签的具体规则 | 仅有标签名称与「规则不同」的性质（turn 16） |
| 贡献值 → 兑换点的汇率 | 无素材（小说示例不构成本项目设定） |
