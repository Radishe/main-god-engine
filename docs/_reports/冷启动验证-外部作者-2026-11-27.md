### 3.1 "文档说可以 / 文档说拒，但 CLI 行为相反"

### 3.2 "文档没说但必须做 / 只能靠猜或照抄"

1. **`credit_delta` 必须填 0**：文档只说"必填整数"和"带 claims 必须为 0"，但**没解释为什么作者不该填收益**。我照抄 D1/D2 填 0；若按"探索副本成功应有奖励"的直觉填正数且带 claims，会被 P1 拒绝。这是靠照抄规避的隐式规则。
2. **`volume=12` / `score=12` / `main_share=1.0` 的取值**：`README.md:33` 只说 `volume` 是"理论最高分"，但**没给任何计算方式或参考区间**；D20/D21 的评分数值被 `REVIEW.md:17`、`SCHEMA.md:35` 反复声明"以 config 为准 / 未拍板"，而 config 对我不可读。我从 D1 抄来 12，作为"能过 CLI"的答案。**这是文档自足性最大的洞**：陌生人能过校验，却不知道自己填的数字是否语义正确。
3. **`idempotency_key` 格式**：文档只说"string，用于幂等去重"，我猜 `D3-EXPLORE-001`。CLI 接受任意字符串（未探测但显然无格式校验）。
4. **`event.kind` / `label` / `completion_basis` 的允许词表**：文档说"string / 自由文本"，P9 证明 `completion_basis` 填 `total_garbage` 也过。这些字段实际是**纯装饰**，文档没说它们可以完全乱填。
5. **文档"唯一真源"不可读**：`SCHEMA.md:9,10,17,22,31`、`CONTRIBUTING.md:9,11,16` 等把令牌表、字段集、公证词汇表、checklist 的真源都指向 `gates/stubs/`、`config/`。对"只拿公开文档"的作者，这些引用是**黑洞**——文档说"以 X 为准"，但 X 不在可读清单里，我无法自查 `asset_ids`/`ability_ids` 到底哪些合法，只能填 `[]` 或抄 D1。

### 3.3 另一个顺序耦合（文档已明说，但值得强调）

`README.md:8` 和 `SCHEMA.md:22` 都强调"先落声明再交清单"，因为 CLI 会查 `instance_id` 是否命中已落盘的 `instance.json`。我如实按顺序做了。若有人先交清单，会遇到作者模板 `:81` 列的 `invalid_field:instance_id` + `is not a loaded instance`。这是**明说的耦合**，不算隐藏，但属于"顺序不对必拒"。

## 4. CLI 通过但设计上不该通过的情况

有，且不少——这正是"CLI 通过 ≠ 设计合规"的现实注脚（作者模板 `:67` 自己也承认）。

| 探测 | 通过的内容 | 为什么我认为设计上不该通过 |
| :-- | :-- | :-- |
| **P2** | `main_share=0.1, side_share=0.9` | 虽然加总 1.0，但**主线只占 10%，违反"主线 ≥ 0.5"的设计规则**（`README.md:61`）。一个主线失败/边缘化的副本被 CLI 判为合规，评分链会怎么算作者完全看不到。 |
| **P3** | `oxygen=999999` | 氧气值 999999 明显不合常理，且 `docs/README.md:37` 说轴范围 0–100 由主神统一持有。CLI 放过一个越界 4 个数量级的轴值。 |
| **P6** | `scene_tag="unknown_xyz"` | 文档明列枚举只有 `peaceful/raid/contract`，未知标签"拒绝"（`SCHEMA.md:43`），CLI 却接受一个完全不存在的标签。 |
| **P9** | `completion_basis="total_garbage"` | 文档说这是 string，于是垃圾值也过。这字段若本意是"完成依据"的证据，至少应限制在有意义取值内。 |
| **冷启动本身** | `volume=12, score=12` | 我抄来的数字**没有任何项目内依据**（文档不给算法、config 不可读），却成了"合规副本"的一部分。CLI 判定的是"格式对"，不是"数值对"——一个语义上可能完全错误的副本被绿灯放行。 |

**结论**：CLI 是纯结构门，把"语义是否正确"的责任完全外包给作者和 L1 人工审核（`REVIEW.md:30`）。但文档同时又说审核者"只做二元判断、不需要理解副本玩法"（`REVIEW.md:30`），两处合起来意味着**这些设计违规可能谁都不会拦**。

## 6. 我最终写了什么
