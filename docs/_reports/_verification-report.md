
**性质判定**：这**不是编造，但属于对素材的删节性改写**，且该节**未标注来源、也未声明为节选**（同章 3.1、1.1、2.1 各节都有「> 来源：…」标注，唯独 3.2 没有）。删去的内容承载了实质规则——「低阶玩家进高阶副本时永久死亡如何降级处理」——删掉后该行只剩半句结论，**信息量下降**。

**建议**：二选一——(a) 把 05 章 3.2 表格恢复为与 07 章一致的完整原文并补「> 来源：generate_docs.py 07 章第 5 节」；或 (b) 保留简表但补注「本表为 07 章第 5 节的节选，完整表述含『死亡降级为严重失败 + 高额扣点』」。
