## 一、审计的自我勘误（Lead 承认的错）

### E1 · N1 的算术笔误（**结论成立，数字订正**）

| | 内容 |
| :--- | :--- |
| **原报告** | 「十阶下限推得 **2047000**」 |
| **实际** | 十阶区间为 `1023000 ~ 2046999`，**下界 = 1023000**，2046999 是**上界** |
| **错误性质** | 把区间**上界**当成了**下界**（表格正确，结论段的取数写错） |
| **影响** | 原报告称"差 2.67 倍"→ 应为 `1023000 ÷ 768000 ≈ **1.33 倍**` |
| **核心结论** | ✅ **仍成立** —— 1023000 ≠ 768000，三项数值仍不可共存 |
| **发现者** | 第二轮复核代理 |

> **教训**：表格自动生成正确，但结论段**手写取数**出错。**机械生成的表 + 手写的结论**是危险组合。

### E2 · N2 的表述误导（**非矛盾，是歧义**）

| | 内容 |
| :--- | :--- |
| **原报告** | 「阶位系数：翻倍与 512.0 **差一阶**」（暗示矛盾） |
| **实际** | `log₂(512/0.5) = 10`、`log₂(512/1.0) = 9` —— **两者都能自洽**，取决于"新手"是否计入翻倍次数 |
| **错误性质** | 标题用了"矛盾"框架，实际是**表述歧义**（"阶"的计数起点未定义） |
| **严重度** | 中 → **低** |
| **发现者** | 第二轮复核代理 |

> 保留为**表述问题**（需明确"新手算不算第 0 阶"），但**不是数值矛盾**。

### E3 · 第一轮子代理的 F1 数字（**结论成立**）

第一轮审计称「十阶下限 = 512000」——这与 Lead 独立验算一致（`1000 × 2⁹`）。
**但该模型建立在"下界每阶翻倍"的假设上**，而文档另给了"一阶 1000~2999 / 二阶 3000~5999"两个样本，二者不相容。

**结论**：`768000` 是异类**成立**（`512000÷512=1000` 闭合，`768000÷512=1500` 不闭合）。
**但"应改为 512000"这个建议需附加条件**：仅当采用"下界翻倍"模型时成立。

## 二、被证伪/降级的发现

### E4 · F9 循环论证（**Lead 承认，降级**）

| | 内容 |
| :--- | :--- |
| **原报告 F9** | 用「体量下限」列 1000/2000/4000/8000 论证"收益每阶 ×4、体量每阶 ×2 → 失衡" |
| **问题** | 2000/4000/8000 **不是文档值**——文档只给了「一阶 1000~2999」「二阶 3000~5999」。那三个数是从 **N1 中已被证伪的"下界翻倍"曲线**推出来的 |
| **错误性质** | **循环论证**：用一个与文档冲突的曲线，去论证文档的数值失衡 |
| **乘法本身** | 1000/4000/16000/64000（收益）计算正确 |
| **裁定** | ❌ **降为「无法据此判定失衡」**。要论证 F9，须先定阶位表（G3），不能先借曲线 |
| **发现者** | 第二轮复核代理 |

> **这是本次审计最值得记住的错误**：它表面上"有表格、有算式"，实质是**用自己的假设证明自己的结论**。
> **机械计算正确 ≠ 论证有效**——数据来源必须先过关。

### E5 · N2 复核方的补充反证（**采纳，加强 N1**）

复核方给出比 Lead 更干净的反证，Lead 采纳：

> 由 `L(2) = 3000` 可定出 `r = 3`，
> 则 `L(10) = 1000 × 3⁹ = **19,683,000**`，
> 是文档值 `768000` 的 **25.6 倍**。

**这比"下界翻倍模型"更直观**——因为它**只用了文档自己给的两个数**（一阶 1000、二阶 3000），不引入任何外部假设。

> 归入 N1 的证据链，作为**首选反证**。

### R1 · A6「基准分」—— **部分证伪，但复核方也过冲**

**复核方主张**：`08:34` 的「基准分」= `06:51` 的「基准值」= 物品 base_value，属**术语漂移**，不是"从未定义"。

**Lead 裁定**：**复核方过冲了。**

**关键证据**：checklist 第 5 项与第 7 项是**两个不同的宾语**：

| 项 | 原文 | 宾语 |
| :--- | :--- | :--- |
| **第 5 项** | 理论最高总**评分** ≥ **基准分** × 该阶位最低比值 | **副本/任务**的评分体系 |
| **第 7 项** | 公证**物品/能力**建议**基准值**在品质参考区间内 | **物品/能力**的定价体系 |

- `06:51`「品质对应**基准值**参考区间」→ 明确绑定**物品品质** → 只对应**第 7 项**
- `01:218`「任务有明确的**基准分**」→ 明确绑定**任务** → 对应**第 5 项**
- `08:13` L0 职权「修改物品/能力**基准值**」→ 同样只对应物品侧

**结论**：

| 项 | 状态 |
| :--- | :--- |
| 第 7 项的「基准值」 | ✅ **已定义**（06:51，品质→区间） |
| 第 5 项的「基准分」 | ❌ **仍是未定义** —— 全文 10 次出现，无一处给出定义 |
| 「该阶位最低比值」 | ❌ **无任何数值** |

**因此 A6 的核心主张（第 5 项三个符号未定义）成立**，只是**不能笼统说"基准分/基准值都未定义"**——须区分两项。

**修正后的表述**：
> checklist 第 5 项的「基准分」「该阶位最低比值」未定义；第 7 项的「基准值」**已定义**。
> 两处用词相近但**指代不同对象**，属**易混**而非**漂移**。

**严重度**：保持 **高**（第 5 项导致审核者无法执行）。

### R2 · 复核方的新发现「基准分 = 基准值」—— **不采纳**

见 R1。两者宾语不同（副本评分 vs 物品定价）。

> 归入 **F3（D1 架空押金）** 的证据链，作为其最硬的内部矛盾证据。

### G2 · 「基础产出值」与阶位区间**量纲耦合** ✅ **采纳**

`F5` 只说「基础产出值无表定义」。复核方进一步指出：

> 若 T4 采纳"体量落在 1000~2999 即一阶"，则一阶副本
> `基础产出值 ≤ 2999 ÷ (阶位系数 1.0 × 完成度 S 2.0) = **1499.5**`
> → **「基础产出值」被阶位区间反锁死**，两套数值必须**联合拟合**。

**Lead 裁定**：**采纳**。这是 F5 的实质性加强——不是"缺一张表"，而是"该表与阶位表**必须同时定义**，否则无法拟合"。

### 关于 A1 的"字面证伪"为何不采纳

复核方主张：A1 的"冲突"字面上可解——只要 `permanent` 被排除在 C 类之外即可。

**Lead 不采纳的理由**：

1. **排除 `permanent` 会使 D1 的立法意图失效**——玩家可把资产转成 `permanent` 规避惩罚，**这正是 D1 废除旧押金公式的头号理由**（"惩罚深度被资产结构反向操控"），换个形式复活。
2. **文档对此零交代**：`06:66` 已为 `droppable` 写明"死亡或严重失败时**概率掉落**"——说明作者**想到了惩罚会动物品**，却对 `permanent`/`tradable` 完全沉默。**这是遗漏，不是有意留白。**
3. 复核方自己也承认这是"遗漏而非有意"，只是要求降调措辞。

**因此 A1 维持"矛盾（高）"**，但**表述调整为**：
> 不是"逻辑上不可能共存"，而是"**两种解法都会破坏一个已拍板设计，而文档未做选择**"。

## 七、审计方法论教训（值得记录）

第二轮复核给出一条**指向性很强**的观察：

> N1 的算术错（2047000）与 N2 的误判（1024.0）**都朝着强化自身结论的方向错**。

Lead 承认这个观察成立：

| 错误 | 错误方向 | 对本方结论的影响 |
| :--- | :--- | :--- |
| N1：把上界当上界当下界（2047000 vs 1023000） | 夸大矛盾（差 2.67 倍 vs 实际 1.33 倍） | **强化**"数值矛盾严重" |
| N2：把第 11 阶当第 10 阶（1024 vs 512） | 凭空制造矛盾 | **强化**"存在数值矛盾" |
| F9：用自己推的曲线论证文档失衡 | 循环论证 | **强化**"收益失衡" |

**这不是巧合，是系统性偏差**：当审计者**先形成"文档有问题"的判断**，验算会不自觉地偏向支持该判断的方向，且**缺少交叉核对**（正确做法：用两种独立路径算同一个数，一致才采信）。

### 已采取的补救

1. **所有数值结论均标注验算路径**，便于他人复核
2. **本次勘误公开保留**，不隐藏审计自身的错误
3. **对本报告数值的使用建议**：
   - 「位置指向」可信——**哪些地方有问题**，两轮审计高度一致
   - 「具体数字」须复核——**尤其当该数字恰好强化"有问题"的结论时**
   - 「可解性」已降调——多数问题**需用户拍板**，不是"已有解法"

> **给后续使用者的一句话**：本套审计报告的**价值在"问题地图"，不在"数值结论"**。
> 修文档前，请对任何数字做一次独立验算。
