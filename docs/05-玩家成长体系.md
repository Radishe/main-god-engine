# 05 · 玩家成长体系

> **素材完整度：部分。** 属性上限、熟练度、感知属性、永久死亡保护、晋升试炼、公证成长路径有素材。
>
> ⚠️ **重要修正**：本章原先称「**降阶**」为"素材缺口"（对话没提所以留空）——
> 但审计发现**它是机制缺口**：本框架自己发明的两条机制**联合要求降阶必须存在**。
> 详见 §0.2。**这不是"等素材"，而是"必须设计"。**

## 0. 审计发现（2026 全量审计）

### 0.1 ⚠️ 属性点被扣后无恢复路径，且会跌穿阶位

**严重度：高** ｜ **阻塞 D1**

| 出处 | 内容 |
| :--- | :--- |
| 本章 §1.1 | 属性上限：一阶 20 / 二阶 40 / 三阶 60 / 十阶 200 |
| 本章 §1.3 | 「永久属性点的投放权必须握在主神手里」 |
| 本章 §7 | 「属性获取途径：**无素材**」 |
| D1 | 惩罚可扣属性点（**B 类抵扣**） |

**问题一：属性点事实上"只减不增"**

既然"永久属性点的投放权在主神手里"，而**属性获取途径完全没有定义**，
那么属性点在被惩罚扣除后，**没有任何已知途径可以恢复**。
**D1 却把它当作可消耗资源使用。**

**问题二：扣减会跌穿阶位**

- 没有规则说明**扣减下限**
- 三阶玩家（上限 60）被扣到 10 点，**他仍是三阶吗**？

**问题三（最尖锐）：出现"与抹杀态无法区分"的中间状态**

| 出处 | 内容 |
| :--- | :--- |
| [07](07-惩罚与死亡机制.md) §5 | 一阶~二阶「永不触发永久死亡……死亡降级为**严重失败 + 高额扣点**」 |
| 本章 §3.3 | 抹杀后「**属性归零**」是抹杀态的特征 |

一阶玩家属性上限仅 **20**，几次"高额扣点"即可扣穿；
而"属性归零"又被定义为**抹杀态的特征**。

> → 出现一种**未被抹杀、但与抹杀态无法区分**的状态，**全库无定义**。

### 0.2 ★ 「降阶」是**机制缺口**，不是素材缺口

**严重度：高** ｜ **阻塞两项已判"倾向已定"的设计**

本章原先的缺口表写：「**降阶**：完整对话零提及，无素材」。

**但审计发现：本框架自己发明的两条机制，联合要求降阶必须存在**：

| 机制 | 出处 | 为什么要求降阶 |
| :--- | :--- | :--- |
| **永久死亡豁免的降级惩罚** | [07](07-惩罚与死亡机制.md) §5：低阶玩家进高阶副本，死亡"降级为严重失败 + 高额扣点" | 属性/资源被扣后，玩家**可能不再满足当前阶位的要求** |
| **B 类属性点抵扣** | D1：惩罚可扣属性点 | 同上，且**无恢复途径**（§0.1） |

**这意味着**：
- 这不是"等对话素材"能解决的——**对话里永远不会提到本项目自己发明的机制**
- 它**阻塞**两项已判"倾向已定"的设计：感知门槛（§2.2）、永久死亡保护（§3.2）

**必须先回答**：属性/资源跌破当前阶位要求时——

| 选项 | 后果 |
| :--- | :--- |
| **A. 不降阶，仅属性降低** | 需定义"属性不满足阶位要求"是否合法 |
| **B. 自动降阶** | 需定义降阶的触发条件、幅度、是否可逆 |
| **C. 阶位与属性解耦** | 阶位只由"历史进度"决定，与当前属性无关——**但这样 09 章的属性上限表就失去约束力** |

### 0.3 ⚠️ 「玩家阶位」是**循环定义**

**严重度：中**

「玩家阶位」全库**无独立定义**（本章 §7 自述"无玩家阶位与副本阶位的关系定义"），
但它被**直接使用**于：

| 使用处 | 用途 |
| :--- | :--- |
| D3 | 准入判定（主神按等级/阶位匹配副本） |
| [07](07-惩罚与死亡机制.md) §6 | 逾期押金基数 |
| 本章 §1.1 | 属性上限 |
| 本章 §3.1 | 效率系数加成上限 |

**循环**：惩罚 → 副本阶位 → 玩家阶位 → 评分区间表（归属未定，见 [04](04-副本阶位与家族.md) §0.3）

> **[04](04-副本阶位与家族.md) §0.3 的表归属问题若不解决，"玩家阶位"永远无法定义。**
>
> ✅ **已由 D24 关闭（2026-11-27）**：玩家阶位 = [`config/tiers.json`](config/tiers.json) 这把**共用尺**上的玩家位置（与副本阶位同尺，D21 刻度归属项已定）；循环链在「评分区间表即共用尺本身」处闭合。§1.1 属性上限表（20/40/…/200）是**独立的另一套刻度**，D21 边界已声明不属该表改动，不与体量区间等比同步——两套刻度分工，非冲突。

### 0.4 ⚠️ 永久死亡保护表：**同一张表两行需要两种解释**

**严重度：中**

| 玩家阶位 | 永久死亡保护 |
| :--- | :--- |
| 一阶 ~ 二阶 | 永不触发永久死亡。**即使进入高阶副本**，死亡降级为「严重失败 + 高额扣点」 |
| 三阶以上 | 可能触发永久死亡，且需**副本声明 `lethal: true`** |

**问题**：表头只有一个「阶位」，但两行需要**两种不同的解释**：

- 第 2 行「即使进入**高阶副本**」→ 这里的阶位读作**玩家阶位**
- 第 3 行「需**副本声明** lethal」→ 这里的阶位读作**副本阶位**

**后果**：**一阶玩家进入三阶副本，到底受不受保护？两行给出相反答案。**

> 该表在 [07](07-惩罚与死亡机制.md) §5 有完整保留，两处文字一致——
> **但"两处文字相同"不等于"语义一致"**，问题在于表头歧义，不在文字差异。

### 0.5 ⚠️ 感知属性：硬门槛没有**供给端**

**严重度：中**

本章 §2.2 把感知定义为「解锁隐藏内容」的**硬门槛**（三处重申），
但**感知属性从哪来、如何提升，完全没有定义**（§7 已承认"属性获取途径无素材"）。

> **门槛存在，但通往门槛的路不存在。**

### 1.2 属性轴的开放性

**引擎对数值语义无知**：引擎只遍历 `attributes` 字典做通用结算，不认识任何一根轴的名字（详细机制见 [01-核心设计哲学.md](01-核心设计哲学.md) §2）。

> 推论（**属推论，非素材结论**）：玩家属性轴可能与副本属性轴同为开放字典，但素材中**没有**玩家属性轴的清单、命名规范或与副本属性的换算规则。

### 1.3 属性上限锁

> 来源：turn 12（《轮回乐园》蓝本）

**主神对「裸装属性」设有硬性门槛。** 副本里可以给临时 buff，但**永久属性点的投放权必须握在主神手里**。

> 主神根据结算数据可能强制调整轮回者权限等级（见 [03-评分与评价体系.md](03-评分与评价体系.md) §3）。
>
> ⚠️ 小说设定示例：任意裸装属性达到 50 点才满足某些晋升条件。**此为本项目参考的小说数值，不是本项目已采纳的数值**——本项目属性上限见 §1.1（一阶 20 / 二阶 40 / 三阶 60 / 十阶 200）。

### 2.2 感知属性的特殊定位

**感知属性用「降低门槛」而非「提高概率」。**

隐藏事件有一个「感知阈值」，玩家感知属性达到阈值就自动发现，不需要 roll 概率。感知属性因此成为一个「解锁隐藏内容」的**硬门槛**，价值明确。

详见 [06-物品与公证体系.md](06-物品与公证体系.md) 与 [09-待确认细节.md](09-待确认细节.md) 细节 6。

## 4. 晋升

> 来源：turn 12 / turn 16

### 4.1 强制晋升

> ⚠️ **本节不采纳。** 见 [设计决议记录](设计决议记录.md) **D3**：主神只按等级/阶位决定准入，**不判定综合实力**；而本节的前提正是「主神检测到实力超标」。决议记录「被否定的旧设定」表已明确列为**不采纳**，[03](03-评分与评价体系.md) §3.2 亦已就地标注。以下原文出自《轮回乐园》小说设定，仅作溯源保留。
> 替代方案：[D2](设计决议记录.md)「高阶进入低阶副本原则上禁止」——不需要主神判定实力。

当检测到轮回者**实力远超当前阶位上限**时，主神会**强制提升其等级并开启晋升试炼**，而不是任由其在低阶副本里「炸鱼」。

> 这是「评级权在主神」的体现——玩家不能自行选择留在舒适区刷低风险收益。

### 4.2 晋升试炼

- 主神可**指定一个特殊副本作为试炼场**。
- **该副本的结算规则由主神直接注入，副本作者无权修改。**
- 晋升试炼失败计入严重失败计数（见 [07-惩罚与死亡机制.md](07-惩罚与死亡机制.md) 第 3.1 节）。

### 4.3 晋升试炼的入场资格

特殊事件标记可用于解锁**特殊兑换通道**，例如用标记兑换**晋升试炼的入场资格**（见 [06-物品与公证体系.md](06-物品与公证体系.md) 第 4.1 节）。

## 5. 稀有成长路径：仅在副本内触发的成长

> 来源：turn 16（《无限恐怖》「基因锁」蓝本）

**机制参照**：基因锁的突破**只能在生死边缘的副本内触发，主神无法直接赋予**。

**对本项目的启示**：框架可以设计一些**只在副本内部才能获得、但结算后能被主神公证**的「稀有成长路径」。

**设计意图**：以此激励玩家冒险，**同时保持主神的最终裁决权**——成长发生在副本里，但认可（公证）发生在主神侧。

> 这与 [01-核心设计哲学.md](01-核心设计哲学.md) §4 的结算隔离原则一致：副本内获得的是局部状态，必须经结算清单才能变成永久资产。

## 6. 兑换与公证对成长的影响

### 6.1 产物公证决定能否带出

**未经主神公证的物品或能力，只能在当前副本内使用，无法带出。**

这条规则堵死了副本作者通过私自定义超模道具破坏跨副本平衡的可能——**东西可以用，但想变成「永久资产」，必须走主神的结算通道**。

### 6.2 可交易的持久化平台

> 来源：turn 16（《王牌进化》蓝本）

主神空间可以从「中转站」扩张成一个独立的「第三世界」：轮回者不再只是任务间隙匆匆兑换，而是可以在空间内**交易、交流、形成工会**。

> 这意味着主神框架从纯粹的「任务发布器 + 商店」，变成**具备内部社会与经济系统的持久化平台**。素材未给出该平台的具体玩法规则。

## 7. 素材缺口

| 缺什么 | 现有素材 |
| :--- | :--- |
| **玩家阶位体系** | 仅能从「一阶 ~ 十阶」「新手」的旁证推断存在，**无玩家阶位与副本阶位的关系定义** |
| **晋升条件** | 仅提到「触发晋升条件」「实力远超当前阶位上限」「裸装属性门槛」为小说设定，**本项目具体阈值无素材** |
| **降阶** | 完整对话零提及；**但已由 §0.2 改判为「机制缺口」而非素材缺口**——本框架自己的两条机制联合要求它存在。规则待设计，见 §0.2 与 [技术债 A3/F02/F16](技术债与盲点.md) |
| 属性获取途径 | 无素材（属性如何随副本提升的具体规则） |
| 技能获取与升级 | 除熟练度系数外无素材（技能从哪来、如何提升熟练度、技能上限） |
| 兑换点与属性的换算 | 无素材 |
| 主神空间社交/交易平台的具体规则 | 仅有「可交易、交流、工会」的性质描述（turn 16，小说蓝本） |
